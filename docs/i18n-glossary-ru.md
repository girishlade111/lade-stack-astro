# Lade Stack Technical Translation Glossary & Style Guide — Русский (ru)

- **Целевая локаль (Target Locale)**: `ru` / `ru_RU` (Russian / Русский)
- **Целевая аудитория (Target Audience)**: Бэкенд- и фронтенд-разработчики, SRE/DevOps-инженеры, архитекторы облачных решений, специалисты по ИИ и машинному обучению (инженерный уровень Хабра, профильных технических блогов и сообществ).
- **Тональность (Tone & Register)**: Прямой, профессиональный, инженерный диалог на равных без маркетинговой «воды», без канцелярита и без академической сухости.

## 1. Стиль, тон и грамматические стандарты (Tone & Style Guide)

1. **Инженерный регистр («от разработчика разработчику»)**:
   - Обсуждаем архитектурные решения, компромиссы (trade-offs), граничные случаи и операционную надежность в продакшене.
   - Никаких маркетинговых восторгов («невероятный», «революционный», «волшебный»). Только технические метрики: *«снижает задержку p95 на 40%»*, *«устраняет истощение пула соединений при всплесках нагрузки»*.
2. **Избавление от канцелярита и отглагольных существительных**:
   - Избегайте громоздких конструкций:
     - ❌ *«Осуществление процесса проведения конфигурации масштабирования...»*
     - ✔️ *«Настройка горизонтального масштабирования...»*
3. **Типографика и знаки препинания**:
   - Кавычки в русском тексте: только «елочки» («...»). Если внутри цитаты есть вложенные кавычки — используются „лапки“ („...“).
   - Тире: длинное тире с отбивкой пробелами ( ` — ` ). Дефис ( `-` ) используется только внутри сложных слов (`веб-приложение`, `бизнес-логика`).
   - Буква **ё**: допускается использовать **е**, но написание должно быть единообразным в рамках статьи.
4. **Англоязычные заимствования и терминология**:
   - Общепринятые профессиональные жаргонизмы и международные аббревиатуры (`деплой`, `мердж`, `коммит`, `пул-реквест`, `CI/CD`, `API`, `SaaS`, `RAG`, `LLM`) приветствуются, если они органичны для русскоязычной среды разработчиков.
