## はじめに

CPU ピニング（親和性設定）、NUMA トポロジの最適配置、ストレージ I/O キューの深度調整、そしてパブリッククラウドにおける「ノイジーネイバー（近隣ノイズ）」への対抗策：ミッションクリティカルな本番ワークロードにおいて、安定的で予測可能な VM パフォーマンスを確保します。本ガイドでは、基本概念からトレードオフ、今週から現場へ導入できる本番仕様のワークフローまでを詳しく解説します。

## なぜ重要なのか

- **開発者ベロシティの向上**: プラットフォーム層の不可解な遅延やジッターを解消し、アプリケーション開発者が本来の機能改善に専念できるようにします。
- **システムの信頼性向上**: コンテキストスイッチやリモートメモリアクセスを排除し、テールレイテンシ（Tail Latency）の急激な悪化を防ぎます。
- **コストコントロール**: 既存 VM のリソース限界を引き出すことで、不要な上位ハイスペックインスタンスへの買い替え出費を抑制します。

## コアコンセプト

### 1. 最小の実装スライスから着手する

全台のカーネルパラメータを一括で書き換える前に、まずはエンドツーエンドで動作する単一のバーティカルスライスを完成させます。**本番VMの性能チューニング**においては、最も負荷の高い単一のデータベースまたは計算ノードを対象に計測基盤を整え、初日から可観測性を確立することを意味します。

### 2. 「成功の落とし穴」を広く設ける

個々のサーバーへ SSH ログインして手動で sysctl を叩くのではなく、Ansible や Cloud-Init を使ってインフラコードとしてパラメータを固定します。本番対応の最小スターター構成例：

```typescript
// Minimal production-ready starter
export const config = {
  retries: 3,
  timeoutMs: 5_000,
  circuitBreaker: { failures: 5, cooldownMs: 30_000 },
};

export async function runWithResilience<T>(fn: () => Promise<T>): Promise<T> {
  let lastError: unknown;
  for (let attempt = 1; attempt <= config.retries; attempt++) {
    try {
      return await fn();
    } catch (err) {
      lastError = err;
      await new Promise((r) => setTimeout(r, attempt * 250));
    }
  }
  throw lastError;
}
```

### 3. 真に重要な指標を計測する

| 指標 | 推奨される初期ターゲット |
| --- | --- |
| p95 レイテンシ | < 300 ms |
| エラーバジェット消費率 | < 2% / 30 日 |
| デプロイ頻度 | 毎日 (Daily) |
| ロールバック所要時間 | < 10 分 |

## 本番チェックリスト

1. CPU Steal Time やコンテキストスイッチ回数を含むシステム構造化メトリクスを導入する。
2. チューニングパラメータの有効化・無効化を段階的にテストできる機能フラグを設定する。
3. リリース前に継続的な高負荷ストレステストを実施し、NUMA ノード間でのメモリアクセス遅延を検証する。
4. 発生頻度の高い上位 3 つの障害シナリオ（I/O ハング、カーネルパニック、ネットワークバッファオーバーフロー）に対する運用手順書（Runbook）を整備する。

## よくある落とし穴

> 実際のユーザーが付く前にプラットフォームを過剰に作り込まないこと。早期に選んだ技巧的な技術よりも、適切に選ばれた堅実な技術のほうが遥かに成果を生みます。

- HugePages（巨大ページ）を盲目的に有効化し、アプリ側のメモリアロケータと衝突してパフォーマンスを落とすこと。
- クラウドのバースト可能インスタンス（T 系など）の CPU クレジット枯渇による突発的な急停止を見落とすこと。
- 深夜の緊急呼び出しにつながる CPU Steal Time 急増アラートの未設定。

## まとめ

**本番VMの性能チューニング**は、小さく観測可能なステップで反復を重ねるチームに大きな成果をもたらします。上記のチェックリストを起点に、週に 1 つの課題を自動化し、エンジニアリングの成功を積み重ねていきましょう。
